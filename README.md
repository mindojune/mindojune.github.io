# Do June Min - Personal Website

This is the source code for my personal academic website, built with [Hugo](https://gohugo.io/) and hosted on GitHub Pages.

## About

I'm Do June Min, an NLP & Speech Processing Researcher at the University of Michigan. This website showcases my research, publications, and professional background.

## Website Structure

- **About**: Personal and professional background
- **Portfolio**: Featured projects and work
- **Publications**: Academic papers and research
- **CV**: Professional resume and experience

## Theme

This site uses the [Terminal theme](https://github.com/panr/hugo-theme-terminal) for Hugo, providing a clean, minimal, and retro aesthetic.

## Local Development

To run this site locally:

1. Install [Hugo](https://gohugo.io/installation/)
2. Clone this repository
3. Run the development server:
   ```bash
   hugo server
   ```
4. Visit `http://localhost:1313` to view the site

## Building

To build the static site:

```bash
hugo
```

The generated site will be in the `public/` directory.

## Deployment

This site is automatically deployed to GitHub Pages via GitHub Actions when changes are pushed to the main branch.
